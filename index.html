プライバシーポリシー

最終更新日: 2026年10月8日 ／ ポリシー版: 1.0.1 ／ 対象バージョン: 1.3.9

本プライバシーポリシーは、Chrome 拡張機能「Chatwork To プリセット」（以下「本拡張機能」）における ユーザーデータの取り扱いについて説明します。

本拡張機能は、Chatwork のチャット画面で宛先（To）の入力を手早く行うための補助ツールです。 本拡張機能が行うのは入力欄への文字の差し込みまでで、メッセージの送信は行いません。 送信するかどうかは、常にユーザー自身が Chatwork の画面で決めます。

1. 単一の目的（Single Purpose）

本拡張機能の唯一の目的:
Chatwork のメッセージ入力欄の横にボタンを追加し、ユーザーが「プリセット」として登録した 複数メンバーへの宛先（To）を、ワンクリックで入力欄に差し込めるようにすることです。 よく使う絵文字を入力欄に差し込むボタンを含みます。
本拡張機能は、この目的以外の機能（広告表示、ユーザー追跡、分析計測、第三者へのデータ販売、 メッセージの送信、AI による要約や分析など）を一切持ちません。

2. 拡張機能が扱うデータ（収集する情報の種類）

本拡張機能は、ユーザーが Chatwork（https://www.chatwork.com/）の画面を開いている間と、 ユーザーが設定画面やポップアップを操作した時に、以下のデータを扱います。 Chrome ウェブストアのデータ使用フォームで申告する分類に合わせて開示します。 いずれもユーザーのブラウザ内と Chatwork との間で扱い、開発者を含む第三者へは送信しません。 ただし、プリセットとメンバー一覧（メンバーの表示名とアカウント ID を含みます）は、Chrome の同期機能によって、 同じ Google アカウントでログインしている他のパソコンの Chrome にも複製されます（第3章 3-2）。

Chrome ウェブストアの分類 本拡張機能における具体的内容
認証に関する情報 ユーザーが任意で設定画面に入力する Chatwork API トークン（Chatwork が発行し、 ユーザー自身が取得したもの）。入力した端末の中（chrome.storage.local）にのみ保存され、 他の端末へは同期されません。
Chatwork のログイン ID・パスワードは扱いません。
個人を特定できる情報 宛先の候補として使う Chatwork メンバーの表示名とアカウント ID。 API トークンを設定している場合は、Chatwork API から取得する Chatwork ID、所属組織名、部署名、 プロフィール画像のアドレスも扱います（プロフィール画像のアドレスは保存しません。第3章参照）。
これらは次の方法で得ます。
  • Chatwork API で、開いているチャットの参加メンバー一覧を取得する（API トークンを設定している場合のみ）
  • Chatwork 画面の To の選択一覧に表示されたメンバーの表示名とアカウント ID を読み取る
  • 画面に表示されているメッセージと入力欄の文字から、To の記法（[To:アカウントID]名前）を読み取る
  • ユーザーが設定画面で手動で入力する（アカウント ID と表示名）
本拡張機能はメールアドレスや電話番号を扱いません。
個人的なコミュニケーション メッセージ本文を保存・送信することはありません。
ただし、上記の To の記法を見つけるために、画面に表示されているメッセージの文字と、 入力欄に入力中の文字を、ユーザーの端末内で読み取ります。 そこから取り出して保存するのは、To の記法に含まれるアカウント ID と名前だけです。 本拡張機能が入力欄に書き込むのは、ユーザーがボタンを押した時の宛先（To）と絵文字の記号だけです。 書き込む位置は入力欄のカーソルの位置で、文字を選択している場合は、選択している部分が置き換わります。
ウェブサイトのコンテンツ Chatwork の画面で、次のものを読み取ります。
  • 開いているチャットのルーム ID（ページのアドレスの # 以降の部分）
  • To の選択一覧に表示されるメンバーの表示名とアカウント ID
  • 画面に表示されている Chatwork の絵文字画像のアドレス（ボタンに同じ絵柄を表示するため）
また、ポップアップの「プリセットの設定を開く」を押した時に、表示中のタブのアドレスが Chatwork かどうかだけを確認します。

本拡張機能は、メッセージ本文、添付ファイル、メールアドレス、電話番号を保存・送信しません。 また、位置情報、閲覧履歴、検索履歴、金融や決済に関する情報、生体情報（指紋や顔画像など）は扱いません。

3. データの保管場所と保持期間

開発者が運営するサーバーは存在せず、保存先はすべてユーザーのブラウザ（Chrome）の中です。 保存先は次の2種類です。

3-1. この端末だけに保存するもの（chrome.storage.local）

  • Chatwork API トークン：ユーザーが設定画面で新しいトークンを入力して保存し直すまで保持されます。 他の端末へは同期されません。

3-2. Chrome の同期機能で他のパソコンにも複製されるもの（chrome.storage.sync）

以下は、同じ Google アカウントで Chrome の同期を使っている場合、 Chrome の同期機能を通じて、同期している他の Chrome にも複製されます。

「複製されます」とは、どういうことか
同じ Google アカウントで Chrome にログインしている別のパソコンでも本拡張機能を使っている場合、 そちらの Chrome にも、プリセットと、メンバーの表示名・アカウント ID が自動で現れます。 やり取りは Google の同期の仕組みを経由します。自宅や共用のパソコンで同じ Google アカウントを使っている場合は、 そちらにも表示名が複製されますので、登録する前にご確認ください。
複製を望まない場合は、Chrome 本体の設定（設定 →「あなたと Google」→「同期と Google サービス」→ 「同期する内容の管理」）で拡張機能の同期をオフにしてください。 これは Chrome 全体の設定で、本拡張機能の中から変えることはできません。
  • プリセット：プリセット名、ボタンの色、宛先に含めるメンバー（アカウント ID と表示名、 または「全員」）。ユーザーが設定画面で削除して保存するまで保持されます。
  • メンバー一覧：アカウント ID ごとの表示名、Chatwork ID、所属組織名、部署名。 プロフィール画像のアドレスは保存しません。 メンバーを取得・読み取るたびに追加・更新されます。 本拡張機能の画面には、メンバー一覧を消す操作はありません（消し方は第8章）。

3-3. 保存しないもの

  • Chatwork API から受け取った応答や、画面から読み取った文字は、処理の間だけメモリ上で扱い、 上記で挙げた項目以外は保存しません。
  • 書き出した JSON ファイル（第5章 5-3）は、ユーザーのパソコンに保存されます。 その後のファイルの扱いに本拡張機能は関与しません。

4. 拡張機能が要求する権限と用途

本拡張機能が manifest.json で要求する権限と、その用途は以下のとおりです。 いずれも本拡張機能の単一の目的を達成するために必要最小限のものです。

権限 用途
storage API トークン（端末内のみ）と、プリセット・メンバー一覧（Chrome の同期機能で共有）をブラウザ内に保存するため。
ホスト権限 https://www.chatwork.com/* Chatwork の画面で本拡張機能のプログラム（コンテンツスクリプト）を動かし、 入力欄の横へのボタンの追加、宛先（To）と絵文字の差し込み、メンバーの読み取り、設定画面の表示を行うため。 また、ポップアップで表示中のタブが Chatwork かどうかを確認するため。
ホスト権限 https://api.chatwork.com/* Chatwork の公式 API から、開いているチャットの参加メンバー一覧を取得するため。

コンテンツスクリプトが動くのは https://www.chatwork.com/* のページだけです。 上記以外の権限（タブの一覧、閲覧履歴、ブックマーク、Cookie、ダウンロードの管理など）は要求していません。

5. 外部サービスへのデータ送信（第三者提供）

本拡張機能は、開発者が運営するサーバーへのデータ送信を一切行いません。 インターネットへの通信は、次の 5-1 と 5-2 だけです。 このほかに、同じパソコンの Chrome に入れた拡張機能との間でやり取りする仕組みが 1 つありますが、 ユーザーのデータは一切やり取りしません（5-4）。

5-1. Chatwork API（api.chatwork.com）

  • 送信先：https://api.chatwork.com/v2/rooms/{ルームID}/members （チャットの参加メンバー一覧の取得。読み取りのみ）
  • 送信内容：API トークンと、開いているチャットのルーム ID。 トークンは HTTP ヘッダー（X-ChatWorkToken）で送信し、URL には含めません。 URL に含まれるのはルーム ID だけです。通信は HTTPS で暗号化されます。
  • 受け取って使う内容：参加メンバーのアカウント ID、表示名、Chatwork ID、所属組織名、部署名、 プロフィール画像のアドレス。
  • 実行タイミング（いずれも API トークンが設定されている場合のみ）：
    • Chatwork のチャット画面を開いて本拡張機能が動き始めた時
    • 表示するチャットを切り替えた時
    • 設定画面で「保存して取得」を押した時
  • メッセージの取得・送信、既読化、メンバーの追加や削除など、上記以外の API 操作は行いません。
  • Chatwork におけるデータの取り扱いは、Chatwork の提供元が定めるプライバシーポリシーに従います。

5-2. 絵文字ボタンの画像

  • 入力欄の横に表示する絵文字ボタンの画像は、Chatwork の画面に既に表示されている同じ絵文字画像のアドレスか、 https://www.chatwork.com/packs/images/emoticon2x/ にある Chatwork の絵文字画像から、 ブラウザが通常の画像表示と同じように読み込みます。
  • 読み込みに使うのは決まった画像ファイルのアドレスだけで、本拡張機能がユーザーのデータを付け加えることはありません。
  • ボタンを表示する時に読み込みます。画像を読み込めなかった場合は、絵文字の記号を文字で表示します。

5-3. JSON ファイルの書き出し・読み込み

  • 書き出し：設定画面から、プリセットとメンバー一覧を JSON ファイルとして書き出せます。 ファイルはユーザーのパソコンに保存されるだけで、外部へ送信されることはありません。
  • 書き出すファイルに含まれるもの：ファイルの形式番号、書き出した日時、 プリセット（識別用の値、名前、色、宛先メンバー）、メンバー一覧（アカウント ID ごとの表示名、Chatwork ID、 所属組織名、部署名）。プロフィール画像のアドレスは書き出すファイルにも含めません。
    Chatwork API トークンは書き出すファイルに含めません。
    メンバーの氏名とアカウント ID が含まれるため、ファイルの取り扱いにはご注意ください。
  • 読み込み：ファイルはユーザーのパソコン内で読み込まれるだけで、外部へ送信されることはありません。 ファイルから取り込むのはプリセットとメンバー一覧だけで、それ以外の項目がファイルに含まれていても読み込みません。
    • プリセットは識別用の値、名前、色、宛先メンバーの項目だけを取り込みます。 宛先メンバーは「全員」と、アカウント ID が数字だけのものに限り、1 人につき アカウント ID と表示名、名前の項目だけを取り込みます。 取り込んだプリセットは、設定画面で「保存」を押した時に確定します。
    • メンバー一覧は、アカウント ID が数字だけのものについて、表示名、Chatwork ID、所属組織名、部署名の項目だけを 取り込み、読み込んだ時点で保存します。 ファイルにプロフィール画像のアドレスが書かれていても取り込みません。
    • プリセットが 500 件、メンバーが 3,000 件を超えるファイルは、取り込みを行わず中止し、その理由を画面に表示します。

5-4. 同じパソコンの Chrome に入れた拡張機能との間のやり取り

  • 本拡張機能は、あらかじめ決めた 1 つの拡張機能からの「設定を読み直してください」という合図だけを 受け取れるようにしています。開発者が更新作業のために使うもので、一般には配布していません。
  • 受け取った時に行うのは、本拡張機能自身を読み直すこと（再読み込み）だけです。 返す内容は本拡張機能の名前だけで、プリセット、メンバー一覧、API トークン、 メッセージの文字を渡すことはありません。
  • あらかじめ決めた相手以外から合図が届いた場合は、返事をせずに無視します。 ウェブページから合図を受け取ることはできません。
  • このやり取りは同じパソコンの Chrome の中で完結し、インターネットへの通信は行いません。

本拡張機能は、上記以外の第三者（広告事業者、分析事業者、AI サービスなど）への データの提供・販売・貸与を一切行いません。 外部 CDN、外部フォント、アクセス解析、エラー収集サービスも使用しておらず、 必要なプログラムはすべて拡張機能内に同梱しています。

6. データの使用に関する誓約（Chrome ウェブストア開示事項）

  1. 本拡張機能で扱うユーザーデータは、ユーザーが承認した目的 （Chatwork の入力欄への宛先の差し込み）のためにのみ使用します。
  2. 本拡張機能で扱うユーザーデータを、第三者へ販売・貸与・譲渡しません。 承認された使用法に当てはまらない目的（マーケティング・広告等）でも、第三者へ転送することはありません。
  3. 本拡張機能で扱うユーザーデータを、信用力の判断や融資目的に使用したり、 そのような目的のために第三者へ転送することは一切ありません。

7. セキュリティ対策

  • 入力フォーム保護：API トークンの入力欄は type="password" によるマスク表示とし、 コピー・切り取り・右クリック・ドラッグ・選択を抑止、autocomplete="off" でブラウザの補完履歴に残しません （貼り付けのみ許可しています）。
  • トークンを画面に残さない：設定画面は Chatwork のページ内に表示されるため、 保存済みのトークンを入力欄に表示し直すことはせず、入力されたトークンも保存の操作をした直後に入力欄から消します。 設定の有無は「設定済み／未設定」の表示だけで伝えます。
  • トークンの送信方法：常に HTTP ヘッダーで送信し、URL には含めません。通信は HTTPS で暗号化されます。 Chatwork API との通信は拡張機能の内部（Service Worker）から行い、本拡張機能自身以外からの呼び出しは受け付けません。
  • ログの保護：コンソールログには件数と処理の状態だけを出し、API トークン、メンバーの名前、 アカウント ID、API の応答内容を出力しません。
  • 読み込みの検証：JSON ファイルの読み込みでは、件数の上限、アカウント ID の形式、 取り込む項目を検証します（詳細は 5-3）。
  • リモートコードを実行しません：外部から取得したスクリプトの実行や、 eval 等による動的なコード実行を行いません。

8. ユーザーの権利（削除請求・開示請求）とデータの消し方

本拡張機能が保存するデータは、すべてユーザーのブラウザ（Chrome）の中にのみ存在します。

  • プリセット：設定画面で、消したいプリセットの削除ボタン（✖）を押してから「保存」を押すと削除されます。
  • API トークン：設定画面で新しいトークンを入力して「保存して取得」を押すと上書きされます。 トークンだけを消すボタンはありません（入力欄を空のまま押しても、保存済みのトークンは消えません）。
  • メンバー一覧：本拡張機能の画面から消す操作はありません。
  • 拡張機能の削除（アンインストール）：Chrome の拡張機能管理画面から本拡張機能を削除すると、 その Chrome の chrome.storage.local に保存された API トークンは削除されます。 chrome.storage.sync に保存されたプリセットとメンバー一覧は Chrome の同期機能が管理しており、 同じ Google アカウントで同期している別の Chrome に本拡張機能が残っている場合は、そちらに残ります。

開発者側のサーバーにはデータを保持していないため、開発者に対して開示請求できる保存データはありません。 Chatwork 側に保存されている情報についての開示・削除請求は、Chatwork の提供元へ直接お問い合わせください。

9. 利用上の注意・利用者の責任

  • API トークンの厳重な管理：トークンはユーザー本人と同じ操作ができる鍵です。 万が一漏洩した場合は、速やかに Chatwork でトークンを再発行してください。
  • 送信前の確認：本拡張機能は入力欄に宛先を差し込むだけで、送信はユーザーが行います。 送信する前に、宛先が意図したメンバーになっているかを必ずご確認ください。
  • 書き出したファイルの管理：書き出した JSON ファイルにはメンバーの氏名とアカウント ID が含まれます。 必要な範囲を超えて共有しないようご注意ください。
  • 機微な情報を扱うチャットでご利用の場合：本拡張機能は、To の記法を見つけるためにメッセージの文字を端末内で読み取りますが、 メッセージ本文を保存・送信することはありません。 プリセット名やメンバーの表示名に何を登録するかは、所属する組織の規程に従ってご判断ください。

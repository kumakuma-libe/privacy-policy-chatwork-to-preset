# privacy-policy-chatwork-to-preset

Chrome 拡張機能「**Chatwork To プリセット**」（chatwork-to-preset）のプライバシーポリシー公開リポジトリ。

公開URL: https://kumakuma-libe.github.io/privacy-policy-chatwork-to-preset/

## 公開のしくみ

`main` へ push すると、`.github/workflows/pages.yml`（GitHub Actions）が `index.html` をそのまま GitHub Pages へ配信します。
リポジトリの Settings → Pages の Source は **GitHub Actions** にしてください。
